THOUGHT BUBBLE STUDIO 1.3.0 — WINDOWS TEST
Landscape activation / 6 x 4 inch landscape certificate
Lobby mode / CPU worker / soft cloud physics

1. COPY AND OPEN
Extract the entire Thought Bubble Studio-1.3.0-win.zip archive to a folder
on the Windows PC. Run Thought Bubble Studio.exe from that folder.
Keep all accompanying files together. No Node.js or internet is needed
to run the extracted app. This package is for Windows x64.

2. PREPARE THE STATION
Set Windows Display orientation to Landscape. Full HD (1920 x 1080)
and 4K (3840 x 2160) are supported; laptop 1366 x 768 was also checked.
Connect the event camera. Allow camera access for desktop apps in
Windows privacy settings, and close other apps using the camera.
Install the printer manufacturer's Windows driver, connect the printer,
and confirm Windows can print its own test page. Load 4 x 6 inch
(10 x 15 cm) photo paper with the correct paper type and tray selected.

3. CONNECT THE APP TO THE PRINTER
Press Ctrl + Shift + A, or hold Cyber Thought Bubble for about 2 seconds.
Create a private 6–12 digit operator PIN, or enter the existing PIN.
Open Certificate: confirm 6 x 4 landscape.
Open Station: click Refresh devices, select the event camera and printer.
Leave "Print directly without the system dialog" OFF for the first test.
Click "Save & print test page". This saves the settings and prints a
calibration certificate without adding a participant record.

In the system print dialog confirm:
- The correct event printer.
- Photo paper 4 x 6 inch / 10 x 15 cm (not A4 or Letter).
- Landscape orientation: finished certificate is 6 inches wide, 4 high.
- One copy, colour, correct photo paper type and tray.
- Borderless if supported. Check the driver's expansion/cropping option.
- 100% / actual size if offered; avoid unnecessary enlargement.

Check the physical sheet: all four dashed edges are visible, the text
is readable, colours print correctly, and there is no second blank page.
A "submitted" message means Windows accepted the job; check that the
paper actually comes out. The included printer-test-6x4.jpg can also be
printed through Windows to help compare driver settings.

4. TRY THE FULL EXPERIENCE
Close settings. Stand centrally in view for two continuous seconds.
Up to four pearl clouds should appear beside one participant.
Try two, three or four people together: each should activate independently.
Thoughts should drift and bounce without covering faces or each other.
The app reduces thoughts per person when the screen is crowded.
The live screen should show only Cyber Thought Bubble and a small bottom button.
Tap Create my certificate, then move into position during 5, 4, 3, 2, 1.
Three photographs should be taken automatically without another tap or form.
Select one, then Save & print certificate. Check that the wide group photo
fills the photo area, everyone fits, and every activated person has thoughts.
Try entering the camera view during the countdown; capture should still work
once faces have been visible for two continuous seconds. Try an empty frame:
the app should return to the start button and offer a retry without saving.
Check the paper, faces, thought bubbles, generic participant label and wording.
Switch language with Ctrl + Shift + L and check Arabic on screen and paper.
Try cancelling one print, then use Print again or Records > Reprint.
The selected certificate remains saved when printing fails or is cancelled.

5. TRY DIRECT PRINTING
After a successful physical test, reopen Station, select the event
printer explicitly, enable direct printing, and Save changes.
Print another test page and one participant certificate. Confirm there
is one sheet per job and the same size/orientation as the dialog test.
Printer-driver preferences may also need to be saved in Windows.

6. RECOVERY / EXIT
No printer: install/check its driver and connection, then Refresh devices.
Selected printer unavailable: reconnect it or choose the correct entry.
Camera unavailable: check Windows permissions and other camera apps.
Use Ctrl + Shift + A to reach Toggle fullscreen, Open data folder or Exit.
Existing station records and PIN stay in the Windows user data folder.
Do not use the browser preview for printer testing; use the desktop app.

VERIFICATION BEFORE DELIVERY
Automated checks cover multi-face matching, group readiness and loss, worker
backpressure, moving-crowd collisions, saved records and print failures.
The real detector was exercised with labelled three- and four-face fixtures.
The previous release print rendering checks covered one-page 6 x 4
output; a physical calibration sheet is still required on this printer.
Windows execution and physical printer output still require this test
on the event PC and printer. The printer model was not provided.
